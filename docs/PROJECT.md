# Nowify

## Vision

Nowify is a modern Spotify "Now Playing" dashboard designed primarily for a Raspberry Pi connected to a landscape display.

The goal is to create something that feels like a premium smart display rather than a simple music player.

The UI should be clean, minimal and elegant, taking inspiration from Spotify, Apple Music, Sonos and Google Nest displays.

Authentication will be re-enabled once the interface is complete.

Each visual section should exist as its own component wherever practical.
